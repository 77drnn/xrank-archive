# X Rank Archive 修正パッチ v9

## 変更内容
- Leanny の Splatoon 3 データベースを参考に、一般的な英語ブキ名を日本語のゲーム内表記へ変換。未登録の名称は元の表記のまま表示します。
- ヘッダーに「戻る」ボタンを追加。プレイヤーページでは開く前の画面へ、それ以外ではランキング画面へ戻ります。
- 独立した「過去の名前」一覧ページを削除。検索欄からの過去名検索と、プレイヤーページ内の「名前履歴」は維持。
- 初期表示と検索条件リセット時の件数を TOP500 に変更。
- 見出しを簡潔にし、文字色のコントラストを改善。
- キャッシュバージョンを v9 に更新。

## 適用方法
リポジトリのルートにある `app.js`、`index.html`、`style.css` を、この ZIP 内の同名ファイルで置き換えてください。GitHub Desktop で変更を確認して commit / push します。

## 注意
ブキ名の変換は表示時の辞書方式です。辞書にない英語名は誤訳を避けるため元の表記を維持します。公開リポジトリへの直接 push は行っていません。

参考: https://leanny.github.io/splat3/database.html
日本語名称の照合: https://stat.ink/api-info/weapon3?_lang_=ja-JP
